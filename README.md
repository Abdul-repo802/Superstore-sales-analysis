# Superstore-sales-analysis
Power BI Sales and Profitability Analysis Dashboard
Project Overview

This project focuses on analyzing Superstore sales performance and profitability using Microsoft Power BI.

The dashboard provides insights into sales trends, profit performance, product categories, customer segments, and regional performance to support data-driven business decisions.

Objectives

Analyze overall sales and profitability.

Identify top-performing product categories and sub-categories.

Understand customer segment performance.

Evaluate regional sales and profit trends.

Identify potential areas for business improvement.
